# Order Tracker — Приложение для учёта заказов

Desktop-приложение на Python/Tkinter для управления заказами производства.

## Структура проекта

```
order_tracker/
├── config.py              # Модуль загрузки конфигурации
├── config.json            # Файл конфигурации
├── data_store.py          # Модуль работы с данными (CRUD)
├── external_integration.py # Взаимодействие с внешними программами
├── attach_folder.py       # Скрипт привязки папки из Double Commander
├── gui_app.py             # Основное GUI-приложение
├── orders.json            # Файл данных (заказы)
└── README.md              # Этот файл
```

## Требования

- Python 3.6+
- Только стандартная библиотека Python (tkinter, json, subprocess, webbrowser, urllib.request, os, sys)

## Установка

1. Скопируйте папку `order_tracker` в удобное место
2. При необходимости отредактируйте `config.json`:
   - `double_commander_command` — путь к Double Commander
   - `search_url` — URL внутреннего сайта для поиска ФИО
   - `search_post_data_template` — шаблон POST-запроса
   - `orders_file_path` — путь к файлу данных (по умолчанию `./orders.json`)

## Запуск приложения

```bash
python gui_app.py
```

## Функционал

### Главное окно

- Таблица заказов со столбцами: номер, тип, чертёж, название, количество, срок, заказчик, технолог, комментарий, папка
- Сортировка по любому столбцу (клик по заголовку)
- Поиск по номеру заказа

### Кнопки действий

- **Добавить заказ** — создание нового заказа через диалоговое окно
- **Редактировать** — изменение выбранного заказа
- **Удалить** — удаление выбранного заказа (с подтверждением)
- **Открыть папку** — открытие папки документации в Double Commander
- **Поиск заказчика** — поиск информации о заказчике на внутреннем сайте
- **Поиск технолога** — поиск информации о технологе на внутреннем сайте

## Привязка папки из Double Commander

1. В настройках Double Commander создайте пользовательскую кнопку с командой:
   ```
   python /путь/к/attach_folder.py "%d"
   ```
   где `%d` — текущая директория (или `%p` для пути к файлу под курсором)

2. Перейдите в папку с документацией заказа
3. Нажмите настроенную кнопку
4. Выберите заказ из списка или введите номер вручную
5. Папка будет привязана к выбранному заказу

## Формат данных

Заказы хранятся в файле `orders.json` в формате JSON:

```json
[
  {
    "order_number": "123",
    "order_type": "Изготовление",
    "drawing_number": "Чертёж-01",
    "name": "Деталь",
    "quantity": 10,
    "due_date": "2025-01-15",
    "customer": "Иванов И.И.",
    "technologist": "Петров П.П.",
    "comment": "Срочно",
    "folder_path": "D:/docs/orders/123"
  }
]
```

### Поля заказа

| Поле | Тип | Описание |
|------|-----|----------|
| order_number | строка | Номер заказа (обязательное, уникальное) |
| order_type | строка | Тип заказа (Изготовление, Ремонт и т.д.) |
| drawing_number | строка | Номер чертежа |
| name | строка | Название изделия/детали |
| quantity | число | Количество |
| due_date | строка | Срок исполнения (дата) |
| customer | строка | ФИО заказчика |
| technologist | строка | ФИО технолога |
| comment | строка | Комментарий |
| folder_path | строка | Путь к папке с документацией |
